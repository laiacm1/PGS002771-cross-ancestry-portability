# Cross-PGS T2D analysis

This folder contains the revised cross-PGS type 2 diabetes portability analysis.

The analysis compares EUR-SAS numerical displacement with standardized ancestry-specific T2D effect differences across four published polygenic scores:

- PGS002771
- PGS000036
- PGS002426
- PGS002475

Primary outputs include score-specific Spearman correlations and bootstrap confidence intervals.
